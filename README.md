# backend-pulseira

## Swagger

Com a aplicação rodando, a documentação da API fica disponível em:

- Swagger UI: `http://localhost:8080/swagger-ui/index.html` (ou `http://localhost:8080/swagger-ui.html`)
- OpenAPI JSON: `http://localhost:8080/v3/api-docs`

Se a aplicação estiver rodando em outra porta, substitua `8080` pela porta configurada.
